🌸 荷花圖片辨識檔產生指南

本頁改用 MindAR 官方線上圖片編譯器。MindAR 1.2.x 使用 ES modules，不能透過舊版 window.MINDAR.Compiler 全域物件呼叫，因此舊版產生器會顯示「Compiler 載入失敗」。

請使用套件內附的原始辨識圖卡：下載荷花辨識圖卡

產生 targets.mind

  1. 點擊下方按鈕，開啟 MindAR 官方 Image Targets Compiler。
  2. 將下載的 lotus-card.png 上傳到編譯器。
  3. 按下 Start，等待圖片特徵分析完成。
  4. 按 Download，取得 targets.mind。
  5. 將 targets.mind 與 index.html、lotus-card.png 放在同一個 GitHub Repository 根目錄。
開啟 MindAR 官方圖片編譯器 ↗
重要：一定要使用本套件中的原始 lotus-card.png 編譯。不要用螢幕截圖、重新裁切或經過壓縮修改的版本。若官方編譯器也無法啟動，請改用桌面版 Chrome/Edge，並確認瀏覽器支援 WebGL。
